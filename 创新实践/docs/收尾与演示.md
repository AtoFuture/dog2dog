## 3. 演示启动步骤

### 3.0 一键启动（推荐）

```bash
cd /home/wy/data1/创新实践/external/go2_real_robot/qwen_robotnav
./scripts/run_gui_console_demo.sh                      # 启动后待机
./scripts/run_gui_console_demo.sh --explore            # 启动后自动发 EXPLORE
./scripts/run_gui_console_demo.sh --restart --explore  # 停掉现有实例并重开
```

脚本会依次起：headless Gazebo server（加载 `gz_ros2_control`、自动关 RViz）→
`:2` 上的 GUI 客户端 → 统一运行栈 7 进程 → 网页控制台，然后打印
`http://127.0.0.1:8765`。第一次运行会自动 prepare（约 1 分钟）。

`--restart` 通过 `$OUT/demo.pid` 找到现有实例，按进程树停掉并等它完全退出，
再重新 prepare/启动；不会误杀外层 shell。旧实例如果不是用本脚本启动的
（没有 `demo.pid`），需要先手动停掉。

只重开探索、保留仿真和地图：

```bash
./scripts/send_demo_command.sh STANDBY
./scripts/send_demo_command.sh EXPLORE
```

默认值：domain `227`、partition `gui_demo_227`、display `:2`、
输出 `.runtime/gui_console_demo`。可用
`DEMO_DOMAIN` / `DEMO_PARTITION` / `DEMO_DISPLAY` / `DEMO_OUT` /
`DEMO_WORLD` / `DEMO_ROBOT_MODEL` / `DEMO_CONSOLE_PORT` 覆盖。
`Ctrl+C` 会清理本次注册的子会话及其后代，保留其他运行栈的同名进程。
自定义 `DEMO_DISPLAY` 会同时传给 GUI 和转发服务；`DEMO_CONSOLE_PORT` 会传给网页服务。
私有端口可用 `DEMO_WS_PORT`（默认 `8766`）、`DEMO_VNC_PORT`（默认 `5909`）覆盖，三个端口必须互不相同。

运行栈必须在 `DEMO_READY_TIMEOUT_S`（默认 `180` 秒）内实际发布 `standby`，否则启动失败并清理本次进程。
`--explore` 要求命令发布成功，并观察到 `exploring` 状态后才打印就绪；发布失败或状态超时均返回非零退出码。

> 如果网页和 Gazebo 在同一 display 上，网页窗口不要盖住 Gazebo：
> `x11vnc` 抓不到被遮挡的窗口，画面会黑。远程访问请用 VSCode Ports
> 转发 `8765`，或在自己的电脑上建 SSH 隧道（命令必须在自己的电脑上跑）。

### 3.6 运行中命令（G3 状态机）

最简单的方式是用 helper（默认域 227，可用 `DEMO_DOMAIN` 覆盖）：

```bash
cd /home/wy/data1/创新实践/external/go2_real_robot/qwen_robotnav
./scripts/send_demo_command.sh EXPLORE
./scripts/send_demo_command.sh PAUSE
./scripts/send_demo_command.sh RESUME
./scripts/send_demo_command.sh RETURN
./scripts/send_demo_command.sh ESTOP
./scripts/send_demo_command.sh RESET
./scripts/send_demo_command.sh STANDBY
```

命令大小写不敏感，状态机只接受这些事件：

| 命令 | 允许的当前状态 | 结果 |
| --- | --- | --- |
| `EXPLORE` | STANDBY（要求健康检查稳定） | 开始探索 |
| `PAUSE` | EXPLORE / PAUSED | 暂停；暂停会等待当前导航 goal 进入终态 |
| `RESUME` | PAUSED（要求暂停释放、健康恢复） | 继续探索 |
| `RETURN` | EXPLORE / PAUSED / RETURN | 结束探索并返航；**STANDBY 下会被忽略** |
| `STANDBY` | STANDBY / EXPLORE / RETURN / PAUSED | 回待机；ESTOP 下不允许 |
| `ESTOP` | 任意状态 | 进入急停并取消 G3 的导航目标（逻辑急停，不是物理硬件急停） |
| `RESET` | ESTOP | 清除急停回 STANDBY；取消/健康条件未满足时会被拒绝 |

典型顺序：`EXPLORE`（开始）→ `PAUSE` / `RESUME`（暂停继续）→ `RETURN`（返航）→ 自动回 `STANDBY`。

等价的原始命令（不经过 helper）：

```bash
/home/wy/.enroot/ros bash -lc 'source /opt/ros/humble/setup.bash; export ROS_DOMAIN_ID=227 RMW_IMPLEMENTATION=rmw_cyclonedds_cpp CYCLONEDDS_URI=file:///home/wy/go2_sim_ws/ROS2-Gazebo-GO2/src/docker/cyclonedds.xml; ros2 topic pub --once /g3/command std_msgs/msg/String "{data: EXPLORE}"'
```

页面任务状态应变为「探索中」，地图、位姿、事件开始更新。
