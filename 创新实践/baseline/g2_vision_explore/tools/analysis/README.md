## 脚本 ↔ 文档 对照

全部对应 `docs/真实RGB-D素材实测-1378.md`：

| 脚本 | 产出什么 | 文档章节 |
|---|---|---|
| `probe_bias.py` | 逐条观测只换深度取样方式（p5/p25/p50/p95/single）重算高度 —— **否定「近端偏置是主因」** | §4.6.1 |
| `probe_rawdepth.py` | 原始深度取值分布 + 关键帧窗口里的垃圾占比 | §4.6.2 |
| `probe_gap.py` | 细粒度直方图找**谷底**（定 0.6 m 阈值的依据）+ 垃圾像素空间分布图 | §4.6.2 |
| `probe_floor_fix.py` | 加有效量程下限后的效果（倒挂消失、观测数变化） | §4.6.4 |
| `probe_sweep.py` | **下限 × 分位数** 二维扫描 + 关键帧真值对照 | §4.6.6 |
| `probe_dispersion.py` | corner1_low 上各分位数的 肩宽中位/IQR/深度差/留存率 —— **「不调大」的依据** | §4.6.6 |
| `probe_buckets.py` | 按素材真值活动分段统计产出率 —— **「躺地上段只出 1 条」** | §4.6.7 |
| `probe_tilt_calib.py` | 倾角判据在 1378 上的**独立复现**（方法 B 结论的另一相机验证） | §4.6.8 |
| `probe_hip158.py` | 1.58 m 异常逐帧诊断（关键点/深度/尺寸/平面参数全打） | §4.6.9 |
| `probe_stale.py` | 旧（无校验 RANSAC）vs 新（`fit_floor_plane`）地面拟合对照 | §4.6.9 |
| `probe_158src.py` | **7 个口径**追查 1.58 m 的出处（全部复现不出来） | §4.6.9 |
| `probe_gate_now.py` | 离地高度门现在能不能标定 + 阈值扫描 | §4.6.9 |
| `probe_bestsig.py` | 四个候选信号（髋高/肩高/竖直跨度/倾角）的分离能力对比 | §4.6.9 |
