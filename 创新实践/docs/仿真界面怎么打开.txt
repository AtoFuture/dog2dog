================================================================================
 怎么看机器狗仿真界面 —— 给队友的操作说明
================================================================================

写给谁：想看到 Gazebo 里 Go2 跑仿真画面的队友
谁维护：wy
更新日期：2026-09-18

--------------------------------------------------------------------------------
 先说结论：一共 3 步，大约 5 分钟
--------------------------------------------------------------------------------

    第 1 步  装 VNC 客户端（.exe，见压缩包）
    第 2 步  用 VS Code 把服务器的 5902 端口转发出来
    第 3 步  VNC 连 localhost:5902，密码 311311

    然后就能看到 Gazebo 窗口。

⚠️ 注意：这是**看 wy 的桌面**，不是你自己独立的桌面。
   多个人同时连会看到同一个画面（VNC 支持多客户端）。
   只是"看一眼仿真跑得怎么样"够用；要自己独占操作，见文末「附二」。


================================================================================
 第 1 步：装 VNC 客户端
================================================================================

压缩包里是一个 .exe 安装程序，双击装上就行。推荐这几个之一：

    TightVNC Viewer      体积小，够用
    RealVNC Viewer       界面好些
    TigerVNC Viewer      和服务器端同源

装完不用配置，直接进第 2 步。

（如果压缩包里没有，自己下：https://www.realvnc.com/en/connect/download/viewer/ ）


================================================================================
 第 2 步：用 VS Code 转发端口  ← 这一步是关键，不能跳过
================================================================================

【为什么必须这么做】

服务器的 5902 端口**从外面连不上** —— 中间那层防火墙只放行了 SSH 的 22。
直接填服务器 IP 会一直"连接超时"（不是拒绝，是超时，因为包在中间被丢了）。

但我们本来就有 VS Code 的 SSH 通道是通的，把 VNC 端口搭在这条通道上走就行了。

【怎么做】

    ① 照常打开 VS Code，Remote-SSH 连上服务器
       （和你平时写代码一样，这一步你肯定已经会了）

    ② 菜单：终端 → 终端   （或者按 Ctrl + ` 打开终端面板）

    ③ 看终端**旁边的标签页**，有一个叫「端口 / PORTS」
       点它切过去

    ④ 点「转发端口 / Forward a Port」按钮

    ⑤ 输入：5902      回车

    ⑥ 列表里会出现一行 5902，下面显示一个本地地址
       一般是  localhost:5902  或  127.0.0.1:5902
       记住这个地址（多半就是 localhost:5902）

【它干了什么】

    VS Code 把服务器上的 5902，通过已经建好的 SSH 连接，
    映射到你笔记本自己的 5902。
    于是你笔记本上的 localhost:5902 == 服务器上的 5902。
    完全绕开了防火墙。


================================================================================
 第 3 步：VNC 连上去
================================================================================

打开第 1 步装好的 VNC 客户端，地址栏填：

        localhost:5902

或者：

        127.0.0.1:5902

（有些客户端对冒号后面数字的解释不一样，如果上面两种都不行，试试
  127.0.0.1::5902  —— 双冒号强制当端口号）

点连接 → 提示输密码 → 填：

        311311

进去之后应该看到：

    · 一个 XFCE 桌面（下面有任务栏）
    · 一个 Gazebo 窗口 —— 里面是 warehouse 场景 + 机器狗


================================================================================
 常见问题
================================================================================

【连不上，一直转圈然后超时】
    99% 是第 2 步没做或没做对。
    检查：VS Code 的「端口」面板里，5902 那行在不在、是不是绿色的。
    不在 → 重做第 2 步。
    在但还是连不上 → 换 127.0.0.1:5902 试试。

【密码不对】
    密码是 311311（六个字符，纯数字）。
    注意别输成别的。如果提示密码错误，找 wy 确认。

【连上了但只有一个空桌面，没有 Gazebo】
    说明仿真没在跑（或者刚挂了）。
    找 wy 重启仿真，或者按「附一」自己起。

【画面卡 / 很慢】
    正常。这是通过 SSH 隧道传的远程桌面，本来就不快。
    只是看仿真够用。卡得厉害的话让 wy 关掉 rviz（那个窗口很吃带宽）。

【看到的是登录界面 / 要输 Ubuntu 密码，键盘还打不了字】
    这是历史上踩过的坑（那时候 VNC 起的是 GNOME 桌面，会卡在锁屏）。
    **现在不会了** —— 已经改成 XFCE 无登录界面。
    如果你又看到了，说明 ~/.vnc/xstartup 被改回去了，找 wy。

【Gazebo 窗口突然消失 / 报 X11 connection broke】
    有人在仿真跑着的时候重启了 VNC 显示。
    重启 VNC 会把整块屏幕拆掉，画在上面的程序全断。
    找 wy 重起仿真。**这个坑别自己踩：仿真在跑时不要动 VNC。**


================================================================================
 附一：自己起仿真（可选）
================================================================================

在 VS Code 的终端里（连上服务器之后）：

        ~/go2_sim_ws/run_sim.sh

想换场景：

        ~/go2_sim_ws/run_sim.sh cafe.world

想让它一直在后台跑（关掉终端也不停）：

        cd ~/go2_sim_ws
        nohup ./run_sim.sh > sim.log 2>&1 &
        tail -f sim.log          # 看日志，Ctrl+C 退出看不影响仿真

停掉：

        pkill -f "ign gazebo"
        pkill -f "ros2 launch"


================================================================================
 附二：想要自己的独立桌面（进阶，可选）
================================================================================

上面第 3 步连的是 wy 的桌面，所有人在看同一块屏。

如果你想要自己的——比如自己开 rviz、自己点 Gazebo：

    ① 在 VS Code 终端里起一个属于你的 VNC（换个 display 号，比如 :7）：

        vncpasswd                 # 第一次要先设密码，自己定
        vncserver :7 -geometry 1920x1080 -depth 24 -localhost no

    ② VS Code 端口面板里转发 5907（不是 5902 了）

    ③ VNC 客户端连 localhost:5907，密码用你自己刚设的

注意：display 号别用 :6（那是 hmb 的）、别用 :2（那是 wy 的）。
空着的有 :3 :4 :5 :7 :8 :9 :10。

⚠️ 自己起的 VNC 也是 XFCE 桌面（~/.vnc/xstartup 是共享配置），
   如果你想改自己的桌面，改之前先问一下，那个文件是所有人共用的。
